# Done

The package already ships the shared base layer, the rtok, ketch, and cox brandbooks, the Pyrlyn and listepo logos, the landing theme, and the `pyrlyn-brand-copy` CLI. `dist/` is generated by `build.mjs` and committed so a git install does not need a build step.

### T8. Add the required project files

The project was missing `AGENTS.md`, `done.md`, `roadmap.md`, `ideas.md`, and `toolchain.md`. Done means: all files exist, with the real toolchain (Node, npm) in `toolchain.md`.

Those files are in the repo root. `toolchain.md` lists Node and npm.

### T9. Test token, copy, and pack decisions

`build.mjs`, `bin/pyrlyn-brand-copy.mjs`, and `scripts/check-pack.mjs` decide token merges, favicon arguments, and which import paths must be in the tarball, and nothing checked those decisions outside CI. Done means: `npm test` runs Node's built-in runner against the real modules, and the missing rulebook files are present.

`node --test tests/*.test.mjs` passed 15 tests: token merge and resolve, color and font helpers, copy arguments, and pack gaps. A direct `node file.mjs` run still writes `dist/` and copies logos; importing the modules from a test does not.
